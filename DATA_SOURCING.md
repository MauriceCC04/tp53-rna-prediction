# Data Sourcing

This document describes all datasets used in the project *"Predicting TP53 Mutation Status from RNA Expression Profiles"*, including their origin, contents, and the rationale for their inclusion.

---

## 1. CCLE / DepMap (Cell Line Data)

The Cancer Cell Line Encyclopedia (CCLE) is a large-scale cancer pharmacogenomics project originally launched by the Broad Institute and Novartis. Its data is now distributed through the **DepMap portal** (Cancer Dependency Map, Broad Institute), which releases updated versions quarterly. The three files below were downloaded from the **DepMap 26Q1 public release** at [depmap.org/portal](https://depmap.org/portal/data_page/?tab=currentRelease).

### `Model.csv`
- **Size:** ~679 KB
- **Contents:** One row per cell line model (**2,116 entries**, 34 lineages). Key columns include `ModelID` (primary key used to join all DepMap files), `OncotreeLineage` (cancer lineage, e.g. Lung, Breast), `OncotreePrimaryDisease`, and other metadata such as tissue of origin and culture conditions (49 columns total).
- **Role in project:** Provides the lineage labels used to stratify train/validation/test splits and to group cross-validation folds, preventing the classifier from learning cancer-type identity as a proxy for TP53 status.

### `OmicsSomaticMutations.csv`
- **Size:** ~341 MB
- **Contents:** Long-format mutation callset — **~751,310 rows** across all protein-coding genes (one row per cell line × mutation pair). Relevant columns include `ModelID`, `HugoSymbol` (gene name), `VariantInfo` (mutation consequence, e.g. `missense_variant`, `stop_gained`, `frameshift_variant`, `splice_acceptor_variant`), `LikelyLoF` (predicted loss-of-function flag), `Hotspot`, and functional annotations from SIFT (`Sift`), PolyPhen (`Polyphen`), and AlphaMissense (`AMClass`, `AMPathogenicity`).
- **Role in project:** Source of the binary and multiclass TP53 labels. Filtered to `HugoSymbol == "TP53"` to identify which cell lines carry a TP53 mutation and what type (insertion, deletion, substitution, SNV).

### `OmicsExpressionProteinCodingGenesTPMLogp1.csv`
- **Size:** ~522 MB
- **Contents:** Wide-format gene expression matrix. Rows are cell lines (indexed by `ModelID`), columns are protein-coding genes (~19,000). Values are **log₂(TPM + 1)**, where TPM (Transcripts Per Million) was computed by the DepMap Omics pipeline using RSEM on RNA-seq data aligned to GRCh38.
- **Role in project:** Primary feature matrix for all CCLE-based models. Each cell line's transcriptome (19k-dimensional vector) is used to predict its TP53 mutation status.

## 2. TCGA / UCSC Xena (Patient Tumour Data)

The Cancer Genome Atlas (TCGA) is a landmark NCI/NHGRI initiative that molecularly profiled over 11,000 primary human tumour samples across 33 cancer types. Raw TCGA data is hosted by the NCI Genomic Data Commons (GDC). Rather than downloading and merging ~11,000 individual files via the GDC Data Transfer Tool, we obtained pre-merged, pipeline-consistent matrices from the **UCSC Xena browser** ([xenabrowser.net](https://xenabrowser.net)), which hosts TCGA data processed through the uniform **UCSC Toil RNA-seq recompute pipeline**. All three TCGA files below belong to the **TCGA Pan-Cancer (PANCAN)** cohort on the UCSC Toil hub.

### `tcga_RSEM_gene_tpm.gz`
- **Size:** ~741 MB (gzipped)
- **Source:** UCSC Xena → TCGA Pan-Cancer (PANCAN) → Gene Expression RNAseq → *TOIL RSEM tpm (n=10,535)*
- **Contents:** Wide-format gene expression matrix. Rows are genes (HUGO symbols), columns are TCGA sample barcodes (n ≈ 10,535 samples across 33 cancer types). Values are **log₂(TPM + 0.001)**, computed by the Toil recompute pipeline using RSEM.
- **Why TPM and not the other Xena options:** TPM is the same unit as the CCLE expression file (log₂(TPM+1)), making the two datasets directly comparable and ensuring consistent preprocessing. `expected_count` is better suited for DESeq2 differential expression analysis but not for ML input. `norm_count` is an intermediate normalisation not used in published pan-cancer ML work. The *Batch effects normalized* version (PanCanAtlas EB++) removes cross-cancer variation that is genuine biological signal for this task.
- **Note on pseudocount:** Xena uses +0.001 vs DepMap's +1. Values are re-scaled during preprocessing to a common log₂(TPM+1) space.
- **Role in project:** Primary feature matrix for all TCGA-based models — parallel to the CCLE expression file.

### `mc3.v0.2.8.PUBLIC.xena.gz`
- **Size:** ~62 MB (gzipped)
- **Source:** UCSC Xena → TCGA Pan-Cancer (PANCAN) → Somatic Mutation → *MC3 (public)*
- **Contents:** The MC3 (Multi-Center Mutation Calling in Multiple Cancers) pan-cancer somatic mutation callset — the consensus mutation resource for TCGA, generated by harmonising calls from seven mutation-calling pipelines. **~2,907,335 rows** (one per sample × mutation). Columns: `sample` (TCGA barcode), `chr`, `start`, `end`, `reference`, `alt`, `gene` (HUGO symbol), `effect` (e.g. `Missense_Mutation`, `Nonsense_Mutation`, `Frame_Shift_Del`, `Frame_Shift_Ins`, `In_Frame_Del`, `Splice_Site`), `Amino_Acid_Change`, `DNA_VAF`, `SIFT`, and `PolyPhen`.
- **Role in project:** Source of TP53 binary labels and mutation-type labels (SNP / insertion / deletion) for TCGA samples. Provides SIFT (`is_damaging`) and PolyPhen (`functional_consequences`) annotations. Filter on `gene == "TP53"` to extract TP53 mutations.

### `Survival_SupplementalTable_S1_20171025_xena_sp`
- **Size:** ~2.4 MB
- **Source:** UCSC Xena → TCGA Pan-Cancer (PANCAN) → Phenotype. This is the **PanCanAtlas survival supplemental table** (Liu et al., 2018, *Cell*), redistributed via Xena.
- **Contents:** **12,591 TCGA samples** across **33 cancer types**. Key columns include `sample` (TCGA barcode, joins with MC3 and expression data), `cancer type abbreviation` (e.g. `BRCA`, `OV`, `LUAD` — 33 unique values covering all TCGA cohorts), `_PATIENT`, `age_at_initial_pathologic_diagnosis`, `gender`, `vital_status`, and survival endpoints (`OS`, `OS.time`, `DSS`, `DSS.time`, `DFI`, `DFI.time`, `PFI`, `PFI.time`).
- **Important:** The cancer type column is named **`cancer type abbreviation`** (not `_primary_disease` or `_cohort`). Use this to join to the expression and mutation data on the `sample` column.
- **Role in project:** Provides cancer-type labels for TCGA samples — equivalent to `OncotreeLineage` in `Model.csv`. Used to stratify splits and group cross-validation folds by cancer type. The survival columns are not used for the classification task but could support future survival analyses.

## 3. TP53 Target Gene List

### `tp53_target_genes_fischer2017.csv`
- **Size:** ~2 KB
- **Source:** Manually extracted from the NCI TP53 Database target genes page at [tp53.cancer.gov/target_genes](https://tp53.cancer.gov/target_genes). No direct download link is provided on the page — the gene table was parsed and saved as a single-column CSV.
- **Contents:** 343 HUGO gene symbols representing confirmed direct p53 transcriptional targets, as defined by the **Fischer (2017)** census study (*Oncogene*, PMID 28288132). These genes were identified through a meta-analysis of 15 genome-wide datasets and over 300 single-gene studies, covering biological processes including apoptosis, cell-cycle arrest, autophagy, metabolism, DNA repair, and translational control.
- **Note:** The tp53.cancer.gov page states 350 genes; the displayed table contains 343 unique symbols. This minor discrepancy is an inconsistency on the source page and has no practical impact on feature selection.
- **Role in project:** Third branch of the consensus feature selection strategy. Any gene in this curated list that is present in the expression matrix is retained as a feature regardless of its correlation score — encoding prior biological knowledge about the p53 transcriptional program directly into the feature set.
